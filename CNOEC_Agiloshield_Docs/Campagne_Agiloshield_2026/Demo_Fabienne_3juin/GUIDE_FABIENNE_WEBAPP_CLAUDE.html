Agiloshield + Claude — mode M&A

Pseudonymiser sur agiloshield.com, analyser dans Claude — 5 minutes

Workflow recommandé pour votre réunion des 3–4 juin. Pas d'installation technique : navigateur + Claude.
Avril vs juin : en avril vous aviez testé l'anonymisation (données parfois effacées). Ici : pseudonymisation M&A — noms et SIREN masqués, dates et montants conservés.

Étape 1 — Pseudonymiser sur Agiloshield

  1. Connectez-vous sur agilotext.com/tools/anonymisation (Google / Memberstack).
  2. Sélectionnez le mode Pseudonymiser (pas Anonymiser).
  3. Cochez : PER, ORG, ADR, IDN (personnes, organisations, adresses, identifiants).
  4. Déposez votre bilan DOCX ou PDF → attendez 30 à 80 secondes.
  5. Téléchargez le fichier pseudonymisé et le fichier .properties (clé de restauration).

Étape 2 — Analyser dans Claude

  1. Ouvrez Claude (claude.ai ou Claude Desktop).
  2. Uploadez uniquement le fichier pseudonymisé.
  3. Exemple de consigne :
    « Analyse ce bilan pseudonymisé : structure financière, points due diligence, incohérences. Les noms sont masqués — utilise les chiffres et dates. »
Ne jamais envoyer à Claude : le document original non protégé, ni le fichier .properties.

Étape 3 — Restaurer (optionnel)

Sur agiloshield.com, onglet Restauration : document pseudonymisé + fichier .properties → document d'origine.

Plan secours (jour J)

Si le live web est lent : utilisez le fichier pseudonymisé déjà préparé par Florian (kit démo) et enchaînez directement sur Claude.
