Agiloshield dans Claude

Pseudonymisez vos bilans automatiquement avant analyse — profil M&A

Ce guide installe le skill Agiloshield dans Claude Desktop. Quand vous mentionnez un bilan, Claude le pseudonymise d'abord : noms et sociétés masqués, dates et chiffres conservés.

Prérequis : Claude Desktop (Mac ou Windows), Python 3.8+ installé, fichier .skill fourni par Agilotext.

Installation (5 minutes)

  1. Ouvrez Claude Desktop → Settings (Paramètres) → Capabilities → Skills.
  2. Cliquez Upload skill et sélectionnez le fichier agiloshield-ma-….skill reçu par email.
  3. Redémarrez Claude Desktop si demandé.
  4. Vérifiez que le skill agiloshield-anonymizer apparaît dans la liste.

Utilisation

Dans une conversation Claude, mentionnez simplement votre document :

« Analyse mon bilan : /Users/moi/Documents/bilan-societe-x.pdf »

Claude va :

  • pseudonymiser le fichier via Agiloshield (25–80 s),
  • analyser uniquement la version safe (sans noms ni SIREN),
  • conserver dates, CA, EBE et montants pour l'analyse financière.

Fichiers produits

À côté de votre document, un dossier .agiloshield/ :

  • outputs/*.pseudonymized.pdf — version à utiliser avec Claude
  • keys/*.properties — clé de restauration (ne jamais partager)
Important : en avril vous aviez testé l'anonymisation complète sur agiloshield.com (dates et CA supprimés). Ce skill utilise la pseudonymisation M&A : identité masquée, chiffres intacts.

Restaurer l'original

Demandez à Claude : « Restaure mon bilan avec la clé .properties » — ou utilisez agiloshield.com si besoin.
