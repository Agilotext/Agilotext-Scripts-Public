Résultat des appels live depuis le poste local
- POST /getAnon2JobsInfo répond bien, mais le token chargé depuis .env est refusé avec error_invalid_token
- GET /getToken appelé depuis le poste local retourne error_forbidden_source

Conséquence
- Les tests end-to-end normaux doivent être faits:
  - soit sur une page Webflow autorisée par l’API
  - soit en mode identifiants manuels avec un token valide déjà obtenu côté source autorisée
