Générez votre clé d'automatisation
Cette clé permet à Make, Zapier ou n8n de demander une transcription à Agilotext en votre nom, à partir d'une URL publique vers le fichier audio.
⚠️ Attention : Si vous générez une nouvelle clé, toutes vos clés précédentes seront désactivées. Vos automatisations existantes cesseront de fonctionner.

Configurez votre scénario

Dans votre outil d'automatisation (Make, Zapier ou n8n), créez un module HTTP avec ces paramètres :
📍 URL de l'API : https://api.agilotext.com/api/v1/sendFromAutomation Cliquez ou appuyez sur Entrée / Espace pour copier
📍 Méthode HTTP : POST
📍 Type de contenu (Body type) : application/x-www-form-urlencoded Les champs username, automationToken et url doivent être envoyés en paires clé=valeur encodées (URL-encoded), pas en multipart.
Postman : utilisez Body → x-www-form-urlencoded, pas form-data.
📍 Paramètres à envoyer :
username
votre email
automationToken
la clé générée ci-dessus
url
lien vers votre fichier audio

Optionnel : Recevoir les transcriptions automatiquement

Configurez un webhook pour recevoir vos transcriptions dès qu'elles sont prêtes. Agilotext enverra automatiquement les fichiers PDF à votre outil d'automatisation.
📥 Voir les données reçues par le webhook
username — votre adresse email Agilotext
jobId — identifiant unique de la transcription
agilotextType — TRANSCRIPT ou SUMMARY
filename — nom du fichier PDF
fileUrl — URL sécurisée de téléchargement
dateTime — date et heure de création
Choix de l'outil :
Collez l'URL fournie par votre outil. Sur Make, une URL peut expirer : recréez le webhook puis mettez l'URL à jour ici.
